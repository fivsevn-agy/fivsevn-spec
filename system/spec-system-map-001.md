# System Map
# 仓库结构说明

本文说明 fivsevn-spec 仓库中各主要目录的基本职责。  
本文件只作为结构说明，不替代各目录中的正式规范文档。

---

## 1. 目的

fivsevn-spec 会持续调整和扩展。  
为了避免目录含义混乱，本文件用于说明每个目录主要放什么、不主要放什么。

---

## 2. 目录职责

```text
appendix/
  辅助材料、枚举表、速查表、示例集合。

archive/
  历史文档处理规则、归档策略和旧文件处理说明。

content/
  内容文件本身的规范，例如 frontmatter、正文结构、内容组织方式。

gov/
  行为规则和流程规范，例如 commit message、维护流程、协作规则。

legacy/
  旧文件存放区。用于保存已被新版文档取代、但仍需追溯的历史文件。

source/
  来源、引用、资料类型和证据来源相关规范。

spacetime/
  日期、时间、时间戳和严格时间语义相关规范。

system/
  仓库自身结构、目录职责和系统性说明。

ver/
  版本变化语义的预留目录。当前不作为主要规范入口。
```

---

## 3. 使用原则

- 当前有效规范应放在对应主题目录中；
- 枚举、示例、速查材料优先放入 `appendix/`；
- 旧文件统一移入 `legacy/`；
- README 应只链接当前有效规范；
- `legacy/` 文件不作为当前规范入口；
- 目录含义发生变化时，应同步更新本文。

---

## 4. 当前状态

当前阶段，仓库主要维护以下几类规范：

```text
content      frontmatter 与内容组织规则
gov          commit message 等行为规范
spacetime    日期、时间与严格时间戳规则
source       来源与引用规范
archive      旧文件与归档处理规则
appendix     枚举与速查材料
```

`system/` 和 `ver/` 保持轻量，不急于扩展复杂规则。
